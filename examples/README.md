# Examples

Worked transcripts, so you can see the team run before you install it. Each one is a real shape of task, showing which specialist is called, what it does, and how it hands off. These are illustrative, your exact wording and codebase will differ, but the flow is what kumi actually does.

- [build-an-endpoint.md](build-an-endpoint.md): a full feature routed end to end by the coordinator, from design through build to review.
- [fix-a-failing-test.md](fix-a-failing-test.md): a single debugger called directly to reproduce, root-cause, and fix one bug.
- [review-before-shipping.md](review-before-shipping.md): a reviewer called directly for a read-only, ranked findings pass.
